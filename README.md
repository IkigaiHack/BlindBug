### BLINDBUG v0.3 TEST

**BLINDBUG** to rozwijany projekt CLI związany z cyberbezpieczeństwem, symulacjami phishingu i testami bezpieczeństwa.

Wersja **0.3 TEST** jest kolejnym etapem rozwoju projektu. Narzędzie jest obecnie intensywnie rozbudowywane — dodawane są nowe funkcje, scenariusze, moduły oraz możliwości analizy.

**Planowane i rozwijane elementy:**

* 🖥️ rozbudowany interfejs CLI,
* 🌐 obsługa PL / EN,
* 🎭 różne scenariusze i szablony testowe,
* 🧪 tryby testowe,
* 📊 analiza i raportowanie wyników,
* 📝 system logów,
* 🔐 moduły związane z bezpieczeństwem,
* ⚙️ kolejne funkcje rozwijane wraz z następnymi wersjami.

Projekt **nie jest jeszcze ukończony** — część funkcji znajduje się w fazie testów i będzie rozwijana w kolejnych wersjach.
